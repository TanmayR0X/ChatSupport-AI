AI Customer Support Chat is a full-stack Next.js app for embedding an AI support assistant into any website. Business owners can log in, store business context, and serve customer-facing chat replies generated by Gemini using that context.

## Live Demo

[![Live Demo](https://img.shields.io/badge/🚀_Live_Demo-Visit-0A66C2?style=for-the-badge)](https://chat-support-ai-tr.vercel.app/)

## Tech Stack

| Technology | Purpose |
|---|---|
| Next.js 14 | Full-stack React framework |
| TypeScript | Type-safe development |
| Tailwind CSS | UI styling |
| MongoDB | Data storage |
| ScaleKit | OAuth and SSO authentication |
| Gemini AI | LLM response generation |

## Features

- ScaleKit-based authentication
- Business profile and knowledge management
- AI chat endpoint powered by Gemini
- Chat script integration
- Dashboard for configuration and script setup

## How It Works

1. User logs in with ScaleKit.
2. User adds business details and support knowledge.
3. Configuration is saved to MongoDB.
4. User copies the embed script.
5. Script is added to the website.
6. Customers send messages from the embedded widget.
7. Gemini responds using the saved business knowledge.

## Flow

```text
ScaleKit Login
      ↓
Dashboard Setup
      ↓
Save Config → MongoDB
      ↓
Embed Script
      ↓
Chat script loads /embed
      ↓
Customer Message
      ↓
Gemini AI (system prompt = knowledge)
      ↓
AI Response
```

## Data Model

| Field | Type | Required | Notes |
|---|---|---|---|
| ownerId | String | Yes | Unique ScaleKit user ID |
| businessName | String | Yes | Business name |
| supportEmail | String | Yes | Contact email |
| knowledge | String | Yes |   Knowledge base used by AI to generate replies  |
| createdAt | Date | Auto | Timestamp |
| updatedAt | Date | Auto | Timestamp |

## API Routes

| Method | Endpoint | Description | Auth Required |
|---|---|---|---|
| GET | /api/auth/login | Start ScaleKit login flow | No |
| GET | /api/auth/callback | OAuth callback and set access token | No |
| GET | /api/auth/logout | Clear access token and logout | Yes |
| GET | /api/auth/me | Get current authenticated user | Yes |
| POST | /api/chat | Send message to Gemini | No (ownerId-based) |
| OPTIONS | /api/chat | CORS preflight for chat endpoint | No |
| POST | /api/settings | Create or update business settings | Yes |
| POST | /api/settings/get | Fetch business settings by ownerId | Yes |
